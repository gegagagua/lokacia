# Decisions

One line per decision (date — decision — why).

- 2026-09-16 — TypeScript pinned to 6.0.x (not 7.x) — typescript-eslint supports `<6.1`; TS 7 native compiler breaks the lint toolchain.
- 2026-09-16 — NestJS 11 (docs) although 12 is out — follow ARCHITECTURE.md; upgrade later with its own decision.
- 2026-09-16 — Shared packages compile to CommonJS with `moduleResolution: Node10` (+ `ignoreDeprecations: "6.0"`) — avoids drizzle dual ESM/CJS type hazard and lets NestJS (CJS) consume them; Next apps transpile them.
- 2026-09-16 — PostGIS/pg_trgm live in schema `extensions`, DB `search_path = public, extensions` — the app role is non-superuser (RLS must apply), and `db:reset` can drop `public` without losing extensions.
- 2026-09-16 — Geography columns are generated from `lat`/`lng` (points) and `boundary` GeoJSON (districts) — writes stay plain numbers/JSON; GiST indexes on generated columns.
- 2026-09-16 — drizzle-kit quotes parameterised custom types; `scripts/fix-migrations.mjs` runs after `db:generate`.
- 2026-09-16 — RLS via `app_org_visible(org_id)` using `app.org_id` or explicit `app.bypass_rls = on` (system/admin/jobs); `withOrg()` / `withSystem()` helpers in `@lokacia/db`.
- 2026-09-16 — Local dev machine has no Docker: Homebrew Postgres 17 + PostGIS and Redis are used; `infra/docker-compose.yml` is still provided (PostGIS 16) for other machines/CI.
- 2026-09-16 — Search engine behind `SearchEngine` interface: `postgres` adapter (default, PostGIS + pg_trgm + btree indexes) and `meilisearch` adapter (`SEARCH_ENGINE=meilisearch`). Meilisearch binary unavailable locally.
- 2026-09-16 — Object storage behind `Storage` interface: `local` (files under `storage/`, served by API) default in dev; `s3` adapter for R2/MinIO.
- 2026-09-16 — Seed photos are generated SVG "architectural drawings" served by `GET /v1/media/placeholder/:kind/:seed.svg` — BRAND.md forbids stock photos; neutral placeholders in seeds.
- 2026-09-16 — Money filters in URLs are whole GEL (`priceMax=3000`); API/DB use tetri — human-readable shareable URLs.
- 2026-09-16 — Passport filter keys are camelCase passport fields; booleans must be true, numbers are minimums.
- 2026-09-16 — Frontends call the API through a same-origin rewrite `/api/v1/* → API_URL/v1/*`; access (15 min) and refresh (rotating, 30 d) tokens are httpOnly cookies — SSR pages can forward cookies, no tokens in JS.
- 2026-09-16 — Dev OTP: mock SMS adapter logs the code; in non-production `OTP_DEV_CODE` (default `123456`) is accepted for any phone — makes the demo testable without SMS.
- 2026-09-16 — Dev ports web 3100 / crm 3101 / admin 3102 / api 4000 — 3000/3001 are used by other local projects on the dev machine.
- 2026-09-17 — `QueueService.register` composes multiple handlers per job name — `listings.published` fans out to alerts (P7), demand matches (P6) and CRM matching without modules overwriting each other.
- 2026-09-17 — Saved-search alerts replay each candidate query with `SearchEngine.matches` after a cheap SQL prefilter (businessType/dealType); channels are the ones stored on the saved search; unsubscribe via public token page `/alerts/unsubscribe/<token>`.
- 2026-09-17 — Sitemap index is a route handler at `/sitemap.xml` pointing at `/sitemaps/<id>.xml` (static, business-types, districts, combos, listings-N × 10 000); Next metadata `sitemap.ts` + `generateSitemaps` was dropped because it conflicts with a custom `/sitemap.xml` index.
- 2026-09-17 — SEO landings live at `/<businessType>`, `/<businessType>/<district>` and `/districts/<district>` with data from `GET /v1/seo/landing` (Redis-cached 5 min); empty combo landings are `noindex, follow`.
- 2026-09-17 — Demand contact creates a portal conversation + message (no org) and an in-app/SMS notification; the requester's phone is only shown to the requester themself.
- 2026-09-17 — Billing effects are pluggable per invoice purpose (`BillingService.registerHandler`) — v2 rent/escrow settle through the same checkout/webhook path without circular modules; launch promo never applies to rent/escrow (third-party money).
- 2026-09-17 — Mock hosted checkout completes via `POST /v1/billing/payments/:id/mock-complete` (non-production only), which signs and runs the real webhook handler — the demo exercises signature verification + webhook_events dedupe.
- 2026-09-17 — Launch promo is disabled by storing an empty string in `settings.launch_promo_until` (value column is jsonb NOT NULL).
- 2026-09-17 — Subscription lifecycle: period end → renewal invoice + `past_due` with `grace_until = period_end + billing_grace_hours` (default 72); failed renewal payment → `grace`; grace passed → `expired` + org plan `free`; `cancel_at_period_end` → `cancelled`.
- 2026-09-17 — District average price override is a column (`districts.avg_price_m2_override_minor`) respected by the district stats job.
- 2026-09-17 — Escrow ledger: funded = Dr `escrow:held` / Cr `psp:clearing`; released/refunded = Dr `payable:owner|tenant:<id>` / Cr `escrow:held`; reconciliation checks per-tx balance and held balance vs funded/disputed escrows.
- 2026-09-17 — Lease messages are stored as `notifications` rows (template `lease_message`, payload.leaseId) — no separate table; tenants without an account get SMS.
- 2026-09-17 — Analytics API keys: sha256 hash stored, `lk_live_` prefix, keys without an API subscription get trial limits (10/min, 500/month); usage metered per day × route in `api_usage`.
- 2026-09-17 — Privacy-friendly analytics: no cookies/ids; `session_hash = sha256(ip_hash + UA + day)` rotating daily, query strings dropped.
- 2026-09-17 — Realtime: socket.io gateway at namespace `/v1/ws` on the API port; browser connects directly (`NEXT_PUBLIC_WS_URL`, dev default `:4000`) with the `lk_at` cookie, websocket transport only; UI falls back to polling when not connected — Next rewrites cannot proxy WebSockets.
- 2026-09-17 — Contract PDFs are stored under `contracts/<offerId>.pdf` and served only via `GET /v1/offers/:id/contract` to thread participants (personal data, never a public media URL); fonts: Noto Sans Georgian TTF (OFL) in `apps/api/assets/fonts`.
- 2026-09-17 — Short-term (P21) bookings reuse the `viewings` table with a `short_term` availability slot (kind/price come from the slot) — no new table needed.
- 2026-09-17 — Daily stats aggregation recomputes (listing, Tbilisi day) rows from raw `listing_events` for yesterday+today hourly with upsert — idempotent and self-healing.
- 2026-09-17 — CRM API is one `CrmModule` with per-area submodules under `modules/crm/*`; cross-area coupling goes through the in-process `CrmEventsService` (contact.created → lead distribution / new_lead sequences, deal won → stop sequences, etc.) — areas stay independent and tests deterministic.
- 2026-09-17 — CRM permissions are a static role → permission map in `@lokacia/contracts` (`crmCan`), enforced by `@Crm(perm)` guard in the API and mirrored in the UI; agents see only records assigned to them.
- 2026-09-17 — CRM selected organization persists in a non-httpOnly `lk_org` cookie; every CRM request sends `x-org-id` (SSR and browser).
- 2026-09-17 — Document versions are rows chained by `parent_id` with `content.rootId`; signed/sent versions are immutable. Co-broker status changes by the target org run in a system transaction because the RLS write check only admits the source org.
- 2026-09-17 — CRM offline capture (C23) stores Blobs in IndexedDB (no dependency) and flushes on `online`, on service-worker Background Sync message, or manually; voice notes upload as media kind `document`.
